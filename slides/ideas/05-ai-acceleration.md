# Working idea — AI changes the control loop

## Slide copy

The 2026 mechanism

**AI is not a fourth boundary.**

It changes existing gradients and control-loop gain and delay. It can also reshape existing constraints.

- Candidate-change arrival rate can rise
- Model consumption and infrastructure demand can rise
- Review effort can become more variable
- Human verification remains capacity-limited

**AI can increase actuator gain. Layoffs can reduce controller bandwidth.**

## Speaker notes

Avoid saying that AI simply accelerates movement across every boundary. That makes AI sound like one directional force.

AI changes how quickly candidate work can be generated, how much reaches review, how variable review effort is, how quickly causes can be attributed, and how far the actual operating state can move before feedback arrives.

It also changes the economic control loop. A lower price per token or per inference can stimulate more workflows, longer contexts, more retries, and more agents. Lower unit cost can therefore coexist with higher aggregate spend, infrastructure commitments, and downstream assurance cost.

The result is not automatically unsafe. AI can also strengthen testing, monitoring, diagnosis, and verification. It amplifies the control structure the organization chooses to build.

The dangerous condition is generation accelerating while verification and correction remain bounded.
