# Some recurring characters

## Slide copy

**Some recurring characters**

Reveal 1:

- Sophisticated word guessing machines, using weighted probability, trained on data obtained with or without consent

Reveal 2:

- a.k.a Large Language Models!

Reveal 3:

- any complex distributed software system

Both explanation rows use bold 32px Comic Neue. The LLM label has its own substep below the first explanation.

## Speaker notes


The recurring images are visual shorthand: the AI ball represents AI, including LLMs and agents, and the complex-system drawing represents a complex distributed software system. The audience will see these images throughout the talk. AI participates within these systems.
